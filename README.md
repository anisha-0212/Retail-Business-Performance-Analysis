# Retail Business Performance & Profitability Analysis

## Project Overview
This project analyses retail transaction data to understand business performance, identify profitable and loss-making product categories, and study sales patterns across different regions and time periods.

## Objective
- Analyse total sales and profit.
- Identify profitable and loss-making product categories.
- Compare sales across different regions.
- Understand monthly sales trends.
- Examine the relationship between discounts and profit.

## Dataset
- **Dataset Name:** Sample - Superstore
- **Source:** Kaggle
- **Total Records:** 9,994
- **Format:** CSV

## Tools and Technologies
- **Python:** Pandas, Matplotlib, Seaborn
- **SQL:** SQLite
- **Data Visualization:** Tableau
- **IDE:** PyCharm

## Project Workflow
1. Collected and explored the retail dataset.
2. Cleaned the data using Python and Pandas.
3. Performed sales and profitability analysis.
4. Used SQL queries to extract business insights.
5. Created visualizations using Python.
6. Developed an interactive Tableau dashboard with Region, Category and Order Year filters.

## Key Findings
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Technology generated the highest profit among the three categories.
- The West region recorded the highest sales.
- Tables showed the largest overall loss among sub-categories.
- Higher discount levels were often associated with lower average profit.

## Dashboard
The Tableau dashboard includes:
- Profit by Product Category
- Sales by Region
- Profit by Sub-Category
- Monthly Sales Trend

## Project Files
This repository contains Python scripts, the original and cleaned datasets, SQL queries, Tableau dashboard, chart images and the final project report.

## Limitation
The dataset does not contain stock-on-hand or inventory-days information. Therefore, actual inventory turnover could not be calculated.

## Conclusion
This project demonstrates how Python, SQL and Tableau can be used together to analyse retail data and generate useful business insights for better decision-making.
